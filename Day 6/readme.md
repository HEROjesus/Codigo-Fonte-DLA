# 📘 Dia  06 – Funções

Neste dia, o foco foi o estudo e prática das **funções em JavaScript**, que são essenciais para escrever códigos reutilizáveis, organizados e fáceis de manter.

---

## 📌 Conteúdo Abordado

- Declaração de funções com `function`
- Funções anônimas
- Arrow functions (`=>`)
- Parâmetros e argumentos
- Retorno de valores (`return`)
- Escopo de variáveis
- Funções dentro de funções (funções aninhadas)
- Boas práticas de modularização

---

## 🚀 Como Executar

1. Acesse esta pasta pelo terminal:

   ```bash
   cd funcoes
   ```

2. Execute o(s) arquivo(s) com Node.js:

   ```bash
   node nome-do-arquivo.js
   ```

> Certifique-se de ter o [Node.js](https://nodejs.org) instalado na máquina para executar os códigos.

---

## 💬 Observações

Dominar funções é um passo essencial para qualquer programador.  
Com elas, você pode evitar repetição de código, resolver problemas com mais clareza e escrever programas mais eficientes e organizados.
