
# 📘 Dia 07 – Super Desafio: Aplicação de Finanças

> "A única maneira de ir rápido, é ir bem."

Neste dia foi proposto um **super desafio prático**, integrando diversos conceitos aprendidos anteriormente, como **variáveis**, **condicionais**, **funções** e **operações matemáticas**.

A ideia foi simular uma **aplicação bancária simples**, sem utilizar arrays ou estruturas de dados mais avançadas, focando exclusivamente em lógica e manipulação de variáveis com JavaScript puro.

---

## 📌 Descrição do Desafio

Criar uma aplicação que simule o controle de **duas contas bancárias**, utilizando as seguintes regras:

- Duas contas, cada uma com seu saldo
- Um **limite compartilhado**, que inicia em R$0 e passa a 10% do saldo total quando este atingir R$1000
- Funções para:
  1. Calcular o saldo total das contas
  2. Exibir alertas caso uma conta esteja sem saldo ou no limite
  3. Fazer depósitos (com taxa de 15% se a conta estiver no limite)
  4. Efetuar débitos
  5. Realizar transferências entre contas (se houver saldo disponível)
  6. Converter saldo em real para dólar
  7. Exibir o limite disponível
  8. Exibir juros acumulados do uso do limite

---

## 🧠 Conceitos Utilizados

- Funções personalizadas para modularizar o código
- Uso de parâmetros e retornos
- Condições com `if`, `else if` e operadores lógicos
- Conversões de moeda com base em taxa de câmbio
- Cálculos financeiros com regras de negócio

---

## 🚀 Como Executar

1. Acesse esta pasta pelo terminal:

   ```bash
   cd super-desafio-financas
   ```

2. Execute o script com Node.js:

   ```bash
   node desafio-financas.js
   ```

> Certifique-se de ter o [Node.js](https://nodejs.org) instalado na sua máquina.
