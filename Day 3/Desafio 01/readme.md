# Desafio de Lógica: Operadores

> "O homem não é nada além do que a educação faz dele."  
> **– Immanuel Kant**

## Descrição

Este repositório contém um desafio de lógica com foco em operadores. A proposta é praticar o raciocínio lógico e o uso adequado dos operadores em linguagens de programação, reforçando o aprendizado e a capacidade de resolver problemas de forma clara e eficiente.

## Objetivos

- Praticar lógica de programação
- Compreender e aplicar diferentes operadores (aritméticos, relacionais, lógicos, etc.)
- Desenvolver o pensamento crítico através da resolução de desafios
