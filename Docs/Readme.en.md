## 🛠️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/HEROjesus/Codigo-Fonte-DLA.git
   ```

2. Access the directory:

   ```bash
   cd Codigo-Fonte-DLA
   ```

3. Navigate to the desired day's folder and open the challenge file:

   ```bash
   cd day-01
   ```

4. Run the file using an extension like **Code Runner** (in VS Code):

   ```bash
   Ctrl + Alt + N
   ```

   > Make sure Node.js is installed and properly configured.
