
# 📘 Dia 05 – Laços de Repetição

Neste dia, o foco foi o estudo e prática dos **laços de repetição (loops)** em JavaScript, que são fundamentais para automatizar tarefas repetitivas e percorrer estruturas de dados.

---

## 📌 Conteúdo Abordado

- `for`
- `while`
- `do...while`
- Controle de fluxo com `break` e `continue`
- Laços aninhados
- Uso prático dos loops para percorrer arrays e gerar repetições

---

## 🚀 Como Executar

1. Acesse esta pasta pelo terminal:

   ```bash
   cd lacos-de-repeticao
   ```

2. Execute o(s) arquivo(s) com Node.js:

   ```bash
   node nome-do-arquivo.js
   ```

> Certifique-se de ter o [Node.js](https://nodejs.org) instalado na máquina para executar os códigos.
