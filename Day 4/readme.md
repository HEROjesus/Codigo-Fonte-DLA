
# 📘 Dia 04 – Condicionais

Neste dia, o foco foi o estudo e prática das **estruturas condicionais** no JavaScript, que são fundamentais para controlar o fluxo dos programas com base em decisões.

---

## 📌 Conteúdo Abordado

- `if`, `else if`, `else`
- Operadores relacionais (`==`, `===`, `!=`, `<`, `>`, etc)
- Operadores lógicos (`&&`, `||`, `!`)
- Estruturas de decisão aninhadas
- Uso prático de condicionais em cenários do dia a dia

---

## 🚀 Como Executar

1. Acesse esta pasta pelo terminal:

   ```bash
   cd dia-04
   ```

2. Execute o(s) arquivo(s) com Node.js:

   ```bash
   node nome-do-arquivo.js
   ```

> Certifique-se de ter o [Node.js](https://nodejs.org) instalado na máquina para executar os códigos.

## 💬 Observações

Este é um passo fundamental na construção de lógica de programação.  
Saber quando e como aplicar condicionais permite criar programas mais inteligentes e adaptáveis.
